# Odd Archive Uploader - Privacy Policy

Last updated: November 9, 2026

Odd Archive Uploader is a private tool run by the owner of the Odd Archive YouTube channel. It is not offered to the public. Its only purpose is to upload and manage videos on the owner's own YouTube channel.

## What data the app uses

When the channel owner signs in with Google, the app receives an access token that lets it upload videos and edit video details on that YouTube channel. The app does not access any other Google account, and it does not collect data from viewers of the channel.

## How the data is stored

The access token is stored only in the owner's self-hosted n8n instance, on the owner's own computer. It is not sold, shared with or transferred to any third party, and it is not used for advertising.

## YouTube API Services

This app uses YouTube API Services. By using it you agree to be bound by the YouTube Terms of Service: https://www.youtube.com/t/terms

Google's Privacy Policy applies to data handled by Google: https://policies.google.com/privacy

## Revoking access

Access can be revoked at any time from the Google security settings page: https://myaccount.google.com/permissions
